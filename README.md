# Job Tracker 💼

A responsive, beginner-friendly Job Application Tracker built with **React**, **Vite**, **React Router**, and modern **vanilla CSS**.

![Dashboard Preview](https://via.placeholder.com/800x450.png?text=Job+Tracker+Dashboard)

## ✨ Features

- **Add Applications**: Add company, role, location, status, date applied, job link, and notes.
- **Card-Based Dashboard**: Visual cards with status-colored top accents and badges.
- **Edit & Delete**: Easily modify job application details or remove entries.
- **Real-Time Search**: Search applications instantly by company name.
- **Status Filter**: Filter by `Applied`, `Interview`, `Offer`, or `Rejected` via dropdown or by clicking the status counter chips.
- **Live Counter Chips**: See counts for each application status in real-time.
- **Responsive Design**: Adapts smoothly from desktop two-column view to single-column on mobile.
- **Clean & Commented**: Written in plain JavaScript (React 19) with helpful beginner-friendly comments.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   cd jobtracker
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit:
   ```
   http://localhost:5173/
   ```

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **React Router v7**
- **Vanilla CSS** (Custom CSS variables, glassmorphism, responsive grid)
